🔗 The Chain Rule & Neural Network Backpropagation

How calculus enables deep neural networks to learn by propagating errors backwards through compound function derivatives.

Computational Graph (Forward Pass): x ──[ W1, b1 ]──> z1 ──[ σ(z1) ]──> a1 ──[ W2, b2 ]──> z2 ──[ σ(z2) ]──> ŷ ──[ Loss: 1/2 (y - ŷ)² ] Backward Pass (Chain Rule): ∂L/∂W2 = (∂L/∂ŷ) • (∂ŷ/∂z2) • (∂z2/∂W2) ∂L/∂W1 = (∂L/∂ŷ) • (∂ŷ/∂z2) • (∂z2/∂a1) • (∂a1/∂z1) • (∂z1/∂W1)
