📊 Parameter Footprint & Complexity

Hidden Dim = 32
RNN

Vanilla RNN

h_t = tanh(W_{hh}h_{t-1} + W_{xh}x_t + b)

Single recurrent hidden state. Highly susceptible to vanishing and exploding gradients when sequence length exceeds 15 steps.

LSTM

Long Short-Term Memory

c_t = f_t ⊙ c_{t-1} + i_t ⊙ c̃_t; h_t = o_t ⊙ tanh(c_t)

Maintains a separate additive cell state $c_t$ with Forget ($f_t$), Input ($i_t$), and Output ($o_t$) gates, preserving memories across 100+ steps.

GRU

Gated Recurrent Unit

h_t = (1 - z_t) ⊙ h_{t-1} + z_t ⊙ h̃_t

Merges cell and hidden state with Update ($z_t$) and Reset ($r_t$) gates. 25% fewer parameters than LSTM with comparable performance.

🛡️ Regularization in Deep Learning & Transfer Learning

Preventing overfitting with Dropout, Batch Normalization, and Early Stopping, plus leveraging pretrained CNN backbones.

📉 Generalization Gap: Unregularized vs Regularized

Dropout (p=0.4) + BatchNorm

Regularization Techniques

Mechanisms
1. Dropout (p = 0.2 – 0.5)

Randomly deactivates a fraction of neurons per forward pass during training. Forces network to develop robust, non-co-adaptive internal features.

2. Batch Normalization (BatchNorm)

Standardizes layer inputs $(\mu = 0, \sigma = 1)$ across the mini-batch with learnable scale $\gamma$ and shift $\beta$, accelerating convergence and smoothing the loss landscape.

3. Early Stopping (Patience = 4)

Tracks validation loss across epochs. Automatically halts training when validation error diverges for $k$ consecutive epochs and restores the optimal weight checkpoint.

🚀 Transfer Learning with Pretrained CNNs (ResNet & MobileNet)

Feature Extraction (Frozen Backbone)

Freeze all convolutional weights (param.requires_grad = False) and train only the newly attached linear classification head. Ideal for small datasets with rapid convergence.

Fine-Tuning (Differential Learning Rates)

Unfreeze top convolutional layers and train with a very small learning rate ($\approx 10^{-5}$), adapting general visual representations to domain-specific datasets.
