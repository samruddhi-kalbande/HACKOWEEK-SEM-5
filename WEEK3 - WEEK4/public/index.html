🐍 Python OOP: StudentRecord Class

Demonstrates Python Object-Oriented principles: Encapsulation (_cgpa getter), computed properties, and methods.

class StudentRecord: def __init__(self, id, name, cgpa, attendance): self.student_id = id self.name = name self._cgpa = float(cgpa) self.attendance = float(attendance) @property def academic_standing(self): if self._cgpa >= 9.0: return "Distinction" if self._cgpa >= 8.0: return "First Class" return "Second Class" def is_eligible_for_placement(self): return self._cgpa >= 8.0 and self.attendance >= 85.0

List & Dict Comprehensions:

  • List Comprehension: [StudentRecord(...) for row in df.iterrows()]
  • Dict Comprehension: {s.id: s.is_eligible_for_placement() for s in students}
  • Conditional Filter: [s.name for s in students if s.academic_standing == "Distinction"]
